# 🚀 Getting Started\n\n## Prerequisites\n- Node.js (v14 or higher)\n- npm or yarn\n- Git\n\n## Setup Instructions\n\n### 1. Clone the Repository\n```bash\ngit clone https://github.com/junaidrazakodingweb/fullstack-web-app.git\ncd fullstack-web-app\n```\n\n### 2. Setup Backend\n\n```bash\ncd backend\ncp .env.example .env\nnpm install\nnpm run dev\n```\n\nThe backend will start on `http://localhost:5000`\n\n**Available endpoints:**\n- `GET /api/health` - Server health check\n- `GET /api/hello` - Test endpoint\n\n### 3. Setup Frontend (in a new terminal)\n\n```bash\ncd frontend\ncp .env.example .env\nnpm install\nnpm run dev\n```\n\nThe frontend will start on `http://localhost:5173`\n\n## Project Features\n\n✅ **React 18** with Vite for fast development\n✅ **Express.js** with modern ES6+ syntax\n✅ **CORS** enabled for cross-origin requests\n✅ **Axios** for HTTP requests\n✅ **Hot Module Replacement (HMR)** for instant updates\n✅ **Environment configuration** with .env files\n✅ **Production-ready structure**\n\n## Development Workflow\n\n1. Backend auto-reloads with `--watch` flag\n2. Frontend auto-reloads with Vite HMR\n3. Make changes and see them instantly\n\n## Building for Production\n\n### Frontend Build\n```bash\ncd frontend\nnpm run build\nnpm run preview\n```\n\n### Backend for Production\n```bash\ncd backend\nnpm start\n```\n\n## Deployment\n\n### Deploy Frontend to Vercel\n```bash\n# Install Vercel CLI\nnpm install -g vercel\n\n# Deploy from frontend directory\ncd frontend\nvercel\n```\n\n### Deploy Backend to Render/Railway\n- Push to GitHub\n- Connect repository to Render/Railway\n- Set PORT environment variable\n- Deploy\n\n## Project Structure\n\n```\n├── backend/\n│   ├── src/\n│   │   └── index.js          # Main server file\n│   ├── package.json\n│   └── .env.example\n├── frontend/\n│   ├── src/\n│   │   ├── App.jsx           # Main React component\n│   │   ├── App.css           # Styles\n│   │   ├── index.css         # Global styles\n│   │   └── main.jsx          # Entry point\n│   ├── index.html\n│   ├── package.json\n│   ├── vite.config.js\n│   └── .env.example\n├── .gitignore\n└── README.md\n```\n\n## Troubleshooting\n\n### Backend won't start\n- Check if port 5000 is already in use\n- Try: `PORT=3001 npm run dev`\n\n### Frontend won't connect to backend\n- Ensure backend is running on port 5000\n- Check `VITE_API_URL` in frontend/.env\n- Check browser console for CORS errors\n\n### Dependencies issues\n- Delete `node_modules` and `package-lock.json`\n- Run `npm install` again\n\n## Contributing\n\nFeel free to fork this repository and submit pull requests!\n\n## License\n\nMIT License - feel free to use for personal and commercial projects.\n\n## Support\n\nIf you encounter any issues, please open an issue on GitHub.\n"
